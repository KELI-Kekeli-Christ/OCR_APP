Scanner de documents Flutter. Le README décrit huit modes OCR, caméra et galerie, live scan, rendu Markdown et LaTeX, export et historique local. Le backend Python est FastAPI avec EasyOCR.

Backend, d’après le README du dépôt :

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Application :

```bash
flutter pub get
flutter run
```
