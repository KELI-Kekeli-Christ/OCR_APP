Escáner de documentos en Flutter. El README enumera ocho modos OCR, cámara y galería, escaneo en vivo, renderizado Markdown y LaTeX, exportación e historial local. El backend Python es FastAPI con EasyOCR.

Backend, según el README del repositorio:

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Aplicación:

```bash
flutter pub get
flutter run
```


La documentación en inglés que ya estaba en este repositorio sigue en el archivo en inglés.
